## 卡 2 · 概念速查（只留最容易卡壳的 5 个）

```
MR-MUF     海力士路线。先把整堆芯片一次性焊好，再灌环氧树脂填缝。
           因为"先连柱子再灌料"，导热铜柱能做得更密 → 散热好。
           类比：先搭钢结构，再灌浆。

TC-NCF     三星路线。每片先贴一层薄膜，再逐层热压。
           低层数时更薄、更可控、更成熟；层数一高就压坏芯片、
           工时长、散热差。
           类比：一层层贴瓷砖，越高越容易贴坏。

           ★ 一句话讲清差别：一个是整体一次成型，一个是逐层压。
             层数少看不出来，堆到 12 层以上就见生死。

TSV        硅通孔。在芯片上打几千个垂直孔连成铜线，数据不用绕
           表面走。⚠️ IBM 发明的，不是海力士。
           类比：仓库大楼里的高速电梯。

内存墙     算力每 18 个月翻倍，内存带宽每 10 年才翻倍。
           1994 年论文预言：CPU 迟早把 90% 时间花在等数据上。
           类比：高速公路修好了，收费站没扩容。

股权链     崔泰源 ─17.7%→ SK Inc. → SK Square → SK海力士
           ← 离婚案就是通过这条链间接影响股价的
```

## 卡 7 · 自测（先别看答案区）

```
Q1  三星产能第一、制程不落后，为什么在 HBM 掉队？说机制。

    这条因果链哪一环最不牢靠？

Q5  本文哪些结论是【推】而非【实】？为什么这个区分重要？
Q6  265 亿和 290 亿分别是什么？混说错在哪？
Q7  "财阀在韩国无所不能"这个印象对吗？用什么例子纠正？
```

```
──────────────── ↓ 答 案 区 ↓ ────────────────

A1  路线选择，不是能力差距。TC-NCF 在 4/8 层有三项真实优势，
    但层数到 12/16 层后热压次数增多 → 压坏芯片、良率降、工时长；
    真正输掉的是散热。良率工时可改善，散热差距随层数放大。

A2  瓶颈在封装不在制程。三家 DRAM 制程差距远小于 58:21:21 的
    份额差距——若制程决定胜负，份额不会这么不对称。

A3  链条：两桩垄断收购 → 现金流 → 三次流拍后接盘 → 投巨资做
    HBM → 卡住 AI。最不牢靠的是**起点**：两桩收购的性质有两套
    对立叙事，视频未调和。其余环节是事实，起点是争议。

A4  产能挤占 1:3。HBM 爆发同时抽走通用内存产能，三条线全线
    涨价是同一原因的多个结果。

A5  【推】：散热是分水岭（分析框架）、4 倍凸点（厂商自述）、
    HBM 缘起于私欲（单方叙事）。【测】：瓶颈到 2030（崔泰源）。
    重要性：把推演讲成事实，一被追问来源就崩。

A6  265 = IPO 已完成融资；290 = 希望筹集的扩产目标。混说会把
    计划说成已完成，或被当成矛盾数据。

A7  军政府时期不是。财阀更像国家意志的工具——政府允许其控制
    经济命脉，同时要求代表国家打国际产业战。例证：全斗焕时期
    釜山国际集团因捐款不积极，20 多天倒闭。
```
