**这份卡片什么时候作废**：
① 美国正式落地限制开放权重的监管
② Qwen3.8-Max 权重开源跳票或高限制开放
③ Anthropic 加入开源联盟或公开前沿权重
④ 前沿闭源与开放模型基准差距重新拉大到一代以上

**标记说明**：【实】可对外说死 ｜【推】加"有分析认为" ｜【测】只能作观点

## 卡 2 · 概念速查

```
开放权重 Open Weight
  公开权重+推理代码，可用可微调；数据与流程仍是机密。
  类比：只给编译好的程序，不给源码。

完全开源 Open Source
  数据、代码、存档、报告全公开；行业代表只有 Ai2 的 OLMo。
  类比：传统软件开源（Linux）才配叫这个名。

★ 一句话讲清差别：开放权重送"答案"，完全开源连"解题
  过程"一起给；当下所有主流"开源模型"都是前者。

技术报告
  讲架构思路、数据构成、踩坑与评测的方法论文档。
  类比：菜谱之于菜品——区分"公关稿"与"真开放"的分水岭。

蒸馏
  用强模型的输出训练自己的模型。
  类比：抄学霸作业；Anthropic 指控中国开源快追的原因。

MaaS（模型即服务）
  把开放权重部署到 GPU 集群再 API 转售。
  类比：二房东——租毛坯、装修、分租赚差价。

vendor verification
  官方对转售 token 质量的认证流程，类似 Intel Inside。
  被收费反而等于拿到官方背书。
```

## 卡 3 · 30 秒讲稿

> AI 行业说的"开源"，绝大多数只是开放权重——送出训练结果这个"答案"，但怎么做出来的仍是机密。中国厂商把这招玩成了进攻：DeepSeek 和 Kimi K3 连详细技术报告带工程工具链一起开，再用许可证给大客户设收费门槛。开源不再是情怀，是竞争打法。黄仁勋发人生第一条推文拉起美国开源联盟，唯独 Anthropic 拒绝加入——因为开放权重打的正是闭源模式的护城河。

## 卡 5 · 追问攻防

```
Q1 权重都开放了，闭源公司不是要被卷死？
A  不会那么快。开放≠放弃商业化：下载后仍需算力、运
   维、定制，云入口/私有化/后训练平台三条收入路径都
   在，月之暗面 ARR 3 亿美元；被冲击的是"靠模型能力
   收租"的部分，不是整个商业模式。

Q2 那是不是越开放越好？
A  对开发者是的，对公司未必。云厂 free ride 是开源
   社区老问题，K3 两道门槛就是针对这个设计的；开放
   程度是商业选择，不是道德评分。

Q3 Anthropic 不加入，是不是说明它心虚？
A  不能这么说死。安全担忧有独立事实面（越狱事件连
   闭源都发生了），蒸馏指控也是公开立场；"商业利益
   是主因"是市场推测，转述要加"有分析认为"。

🚧 该承认不知道的
   · K3 与 MaaS 厂商商业协议的具体分成条款未公开
   · 联盟内部运作细节无公开信源
   · Anthropic 决策过程纯属外部推测
   · "中国抹平美国领先"是视频转述的市场观点，
     未附基准清单，需自行核验
```

## 卡 6 · 讲错风险

```
❌ 许可证张冠李戴：DeepSeek=MIT、Qwen=Apache 2.0、
   K3=自设门槛 License、Llama=限制最多的自定协议
→ 四家四种，混说必错。

❌ "收入超 2000 万美元就禁止使用 K3"
→ 错。门槛①月活超1亿/月收入超2000万美元→展示标识；
   门槛②MaaS 12个月总收入超2000万美元→另行签约。
   是署名/签约义务，不是禁令。

❌ 把 2.8 万亿说成"训练数据量"
→ 2.8 万亿是 K3 权重的参数（浮点数）数量；
   视频特别强调参数规模≠数据大小。

❌ 把"中国抹平美国领先"当既成事实说死
→ 这是视频转述的市场观点，引用带"据市场观点"。

⏳ 模型版本与联盟名单时效性强，超过 3 个月别再引用
   具体版本号与成员名单，改引结构判断。
```

## 卡 7 · 自测

```
题面区
1. "K3 都开源了，训练数据肯定也随便看"——错在哪？
   他以为的那种开源，行业代表是谁？
2. Meta 和 DeepSeek 都叫"开放权重"，为什么 DeepSeek
   是"Plus 版本"？至少两个维度对比。
3. 月活 1 亿 / 月收入 2000 万 / 12 个月 2000 万美元，
   三个数字各卡住谁？
4. 云厂要向月之暗面交钱，嘉宾为何说他们"应该欢迎"？
5. 英伟达、微软、Palantir 加入联盟的动机分别是什么？
   与宣言哪个口号形成反差？
6. 本文哪些论断属于【推】而非【实】？举两例，并说明
   为什么这个区分在"Anthropic 为什么缺席"上特别重要。

──── ↓ 答 案 区 ↓ ────

1. 七步流程中 K3 只开⑤权重+推理代码（外加报告与
   工具链）；①数据④流程仍保密。全公开的是完全开源，
   代表 Ai2 的 OLMo。
2. ①技术报告：Llama 4 只剩一篇博客，DeepSeek V3/R1
   把 MLA、FP8 等细节全写透；②工具链：Meta 从未开，
   DeepSeek 开了 DeepEP/FlashMLA。差异在权重之外。
3. 前两个卡大型应用（超限须展示"Kimi K3"标识），
   第三个卡 MaaS/云厂转售生意（须另行签约）。设计
   意图：散户免费、大户付费、防 free ride。
4. 被收费=与 Kimi 存在官方认证关系；vendor
   verification 保证 token 质量有官方背书，交钱买到
   的是资质不是成本。
5. 微软：模型跑在谁家云上都行，跑我云上就赚钱；英伟
   达：人人自建=多卖铲子，不在乎谁挖到金子；
   Palantir：模型越开放可服务场景越多。反差：宣言谈
   安全/AI 主权，成员名单全是生意。
6. 例：Anthropic 缺席"更多出自商业利益"是【推】
   （"也有很多人认为"）；云厂欢迎收费是【推】（嘉宾
   观点）。区分重要：把动机推测说死=替对方认了"借
   口"；把官方表态当全部真相=忽略护城河利益。
```

## 卡 8 · 立场三选一

```
A 开放就是军备竞赛，越开放越占优
  据：DeepSeek Plus 式开放抬高全行业基准，K3 被迫
      跟上；开放生态带来 Day-0 推理支持与 Agent
      创业的正反馈。
  驳：开放边际收益递减——下一代能力仍取决于算力与
      数据，这两样不随权重开放。
  我错了的信号 ▸ 中国头部厂商下一代旗舰重回闭源
  API-only，或开放与闭源基准差距重新拉大。

B 许可证门槛制是开源商业的新均衡
  据：K3 双门槛实现"散户免费获客、大户付费变现"，
      防 free ride；被收费=vendor verification 背书，
      ARR 3 亿美元初步验证。
  驳：若 DeepSeek/Qwen 继续 MIT/Apache 零门槛，
      开发者会迁移，K3 模式难成标准。
  我错了的信号 ▸ 月之暗面 ARR 增速显著放缓或被迫
  改回 MIT 系；其他厂商无一跟随门槛制。

C Anthropic 缺席主要是商业自卫，安全是次要理由
  据：开放权重直接冲击闭源 API 依赖与能力复制；
      "先管蒸馏"恰好指向保护自身前沿产出。
  驳：安全担忧有独立事实支撑——越狱事件连闭源都
      防不住，前沿能力公开后滥用门槛确实更低。
  我错了的信号 ▸ Anthropic 在无商业压力变化下公开
  前沿权重并附安全评估；或闭源业务被证明不受开放
  模型影响。
```
