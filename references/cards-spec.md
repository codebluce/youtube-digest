# 卡片包规格（Cards Spec）v1.0

> 卡片包是主文之外的**第二个必交产物**。只交主文 = 未完成。
> 文件名：`<video_id>-<slug>-cards.md`，与主文同目录。

---

## 第 0 章 · 设计契约

**主文负责理解，卡片包负责使用。**

- 主文是"读一次"的：叙事、因果、背景铺垫；
- 卡片包是"反复翻"的：记忆、转述、追踪、决策。

因此卡片包**不是主文的缩写版，也不是目录**。它只保留主文中可执行的部分，并且必须能在**不回看主文的情况下独立使用**。

### 三条硬约束

```
① 禁止竖线 Markdown 表格
   卡片包很可能被直接粘贴为飞书消息正文，而飞书不渲染 | 分隔表格。
   所有表格一律用等宽代码块 + ─── 分隔线。

② 禁止 <details> 折叠
   飞书正文不渲染折叠标签，会直接暴露答案。
   自测题的答案改用「答案区」分隔线隔开。

③ 字数上限 3500 中文字
   超过就失去"随时翻"的意义。写不下就砍卡，不砍字号。
```

## 第 1 章 · 卡片锁定表

固定 9 张卡，**顺序锁定，禁止增删**。条件卡由主文的内容分型决定（与 `content-types.md` 一致）。

```
卡号   名称            锚点词          必选性   最小满足量
──────────────────────────────────────────────────────────────
头部   定位与有效期    一句话定位       必      定位1句 + 失效条件(条件型) + 符号说明
卡 1   必记数字        必记数字         必      ≥8 个数字，每个带可信度标记
卡 2   概念速查        概念速查         必      3-6 个最易卡壳的概念
卡 3   30 秒讲稿       30 秒讲稿        必      1 段，可直接念
卡 4   场景变体        场景变体         必      3 个场景
卡 5   追问攻防        追问攻防         必      3 组 Q&A + 🚧 边界
卡 6   讲错风险        讲错风险         必      3-5 条
卡 7   自测            自测             必      与主文同题，答案区分离
卡 8   立场三选一      立场             必      ≥2 个立场，各带"我错了的信号"
卡 9   跟踪表          跟踪表           条      ≥5 指标（跟随 M13 触发条件）
尾部   UP主立场摘要    UP主立场         条      压缩为 3-4 行（跟随 M16 触发条件）
──────────────────────────────────────────────────────────────
```

## 第 2 章 · 各卡规格

### 头部

```
━━━ 标题横幅（视频标题关键词 + "速查卡片包"）━━━
一句话定位（≤40 字，必须是判断句）
这份卡片什么时候作废 —— 引用主文 M03 失效条件（条件型才有）
标记说明：【实】可对外说死 ｜【推】加"有分析认为" ｜【测】只能作观点
```

### 卡 1 · 必记数字

≥8 个，三列等宽表：数字 ｜ 含义 ｜ 可信度标记。

- **易混数字必须相邻排列并加 ⚠️ 警示**（如 265 亿 / 290 亿）；
- 需要打折的数字（厂商自述、CEO 预测）必须在含义列下方加一行 `⚠️` 说明；
- 优先收录：规模数字、份额数字、比例关系、时间节点。

### 卡 2 · 概念速查

3–6 个，只收**最容易卡壳、且讲错会露怯**的概念。

- 每个概念：一句话解释 + 类比；
- 若存在一对相互对立的概念（如两条技术路线），**必须额外给一行 `★ 一句话讲清差别`**——这是主文里没有的，因为主文有整章铺垫，卡片必须一句话说清。

### 卡 3 · 30 秒讲稿

直接引用主文 §2.14.1 的 30 秒版，用引用块（`>`）呈现，不改写。

### 卡 4 · 场景变体

3 个场景（对上级/会议、对朋友/饭局、对同行/行业交流）。

- 与主文一致，但**结尾可留填空占位**指向卡 8，例如：
  `我倾向的判断是〔选卡8的立场〕，证伪信号是〔对应信号〕。`
- 这是卡片包特有的联动设计，主文不需要。

### 卡 5 · 追问攻防

3 组 `Q / A`，加 `🚧 该承认不知道的` 区块。与主文 §2.14.3 一致，可压缩措辞但不得删减组数。

### 卡 6 · 讲错风险

3–5 条，用 ❌ 与 ⏳ 前缀。每条格式：`❌ 错误说法` 换行 `→ 正确说法/原因`。

### 卡 7 · 自测

- **题面区**：只列题目，与主文 M10 同题，可压缩措辞；
- **答案区**：用 `──── ↓ 答 案 区 ↓ ────` 分隔线隔开，答案压缩到每题 2–3 行；
- 禁止使用 `<details>`。

### 卡 8 · 立场三选一

与主文 M12 一致，压缩为等宽块。每个立场必须保留 `我错了的信号 ▸ …` 行——**这是立场卡的核心，删掉就退化成观点罗列**。

### 卡 9 · 跟踪表 `[条件卡]`

≥5 指标，等宽表：指标 ｜ 当前值 ｜ 阈值 ｜ 突破意味着。
表下附一行「看哪里：」列出具体信源。

（主文 M13 是五列含「在哪看」，卡片压缩为四列 + 统一信源行，避免宽度溢出。）

### 尾部 `[条件]`

UP主立场压缩为 3–4 行 + 主文文件名指引 + 免责声明。

## 第 3 章 · 排版规范

```
分隔符    卡与卡之间用 ---（Markdown 水平线）
卡标题    ## 卡 N · 名称
等宽块    ``` 包裹，内部用 ─ 画表，列宽手工对齐
强调      仅用 **粗体**，禁止 HTML
宽度      等宽块内单行 ≤ 62 个半角字符位，避免手机端折行
```

## 第 4 章 · 禁止清单

```
❌ 使用竖线 Markdown 表格
❌ 使用 <details> 折叠
❌ 超过 3500 中文字
❌ 缺少任何必选卡
❌ 调整卡片顺序
❌ 把卡片包写成主文目录（"详见第X章"式的空壳）
❌ 卡 8 省略"我错了的信号"行
❌ 产出了主文未触发的条件卡（如知识科普型出现卡 9）
```

## 第 5 章 · 与主文的内容分配

避免两个文件互相重复或互相缺失，按下表分配：

```
内容                        主文    卡片包
────────────────────────────────────────────
标题/导读/元信息             ✔       压缩为横幅
内容类型/可信度总账          ✔       只留符号说明
失效条件                    ✔       ✔（原样）
阅读路径导航                 ✔       —
30秒速览                    ✔       —（被卡1数字替代）
知识地图                    ✔       —
主体章节（叙事+因果）         ✔       —
数字锚点                    分散在各章  ✔ 汇总为卡1
知识网络（含关系图）          ✔       压缩为卡2（只留易卡壳的）
系统性回顾/金字塔/时间线      ✔       —
闭卷自测                    ✔       ✔（答案压缩）
多空对照                    ✔       —（由卡8立场承载）
立场脚手架                   ✔       ✔（压缩）
跟踪清单                    ✔       ✔（四列）
转述三档主稿                 ✔       只留30秒版
场景变体/攻防/风险清单        ✔       ✔（核心，原样或轻压缩）
延伸思考                    ✔       —
UP主立场                    ✔       压缩为 3-4 行
────────────────────────────────────────────
```

**判断原则**：读一次就够的留主文，需要反复翻的进卡片包，两者都要的原样复制不改写（改写会导致两版说法不一致，是漂移）。
