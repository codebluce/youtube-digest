# 内容分型判定规则 v4.0

> ⚠️ 分型决定两件事：**S6 跟踪指标表是否必选**，以及主体章节的组织方式。
> **判定必须机械执行，不得凭感觉。** 判定结果写进文末附录 A1 的元信息行：`内容类型：<类型名>`

---

## 第 1 章 · 判定流程（自上而下，命中即停）

按顺序检查，**第一个命中的规则决定类型**。不得跳过，不得回头改判。

```
步骤 1  视频是否围绕【一家或数家具体公司/一个具体行业】的经营、竞争、
        财务、股价、供需展开？
        ├─ 是 → 类型 = 公司行业研究型          ▶ 判定结束
        └─ 否 → 下一步

步骤 2  视频是否围绕【宏观经济、货币政策、大类资产配置、市场策略】展开？
        ├─ 是 → 类型 = 宏观策略型              ▶ 判定结束
        └─ 否 → 下一步

步骤 3  视频是否围绕【一个已经发生的具体事件】做还原与复盘？
        （事故、崩盘、并购、战争、政治事件、产品失败）
        ├─ 是 → 类型 = 事件复盘型              ▶ 判定结束
        └─ 否 → 下一步

步骤 4  以上都不是 → 类型 = 知识科普型         ▶ 判定结束
```

**边界裁决规则**（出现争议时按此裁决，不得自行发挥）：

| 情形 | 裁决 |
|---|---|
| 讲公司史 + 讲技术原理（如"某公司崛起史 + 其核心技术"） | 公司行业研究型（步骤 1 优先） |
| 讲宏观 + 顺带点评几家公司 | 宏观策略型 |
| 讲某次崩盘 + 分析行业格局 | 事件复盘型（有明确的"已发生事件"作主线） |
| 纯技术/科学原理讲解，无商业主体 | 知识科普型 |
| 人物传记 | 若落点是其公司经营 → 公司行业研究型；否则 → 知识科普型 |
| 无法判定 | **降级为知识科普型**（保守选择，条件内容最少） |

## 第 2 章 · 类型 → 条件内容触发表

v5.0 蓝图只剩一处条件内容。`✔` = 必选；`—` = 不产出（产出了也算漂移）。

```
条件内容                     知识科普型   公司行业研究型   宏观策略型   事件复盘型
──────────────────────────────────────────────────────────────────────────────
S6 ② 跟踪指标表                 —             ✔             ✔          —
──────────────────────────────────────────────────────────────────────────────
```

**S1–S7 七个正文模块与附录 A1 不受分型影响，所有类型一律产出。**

### 触发说明

- **跟踪指标表**只在金融属性类型（公司行业研究型、宏观策略型）触发。它服务的是"持续跟踪一个可证伪判断"，知识科普与事件复盘没有这个需求，硬加会稀释主文。
  注意：立场本体（含「我错了的信号」）**所有类型都必选**——v2.0 里作为条件模块的"失效条件""多空对照"已并入 S6 立场，不再单独触发。
- v5.0 起附录 A3「立场与利益相关」整块砍除，分型不再决定它。**代价**：UP 主的立场倾向与利益披露不再出现在产出里，信源偏差从此靠读者自己警觉。

## 第 3 章 · 各类型的写作侧重

分型不改变模块集合，但影响主体章节（S4）的组织方式：

```
知识科普型
  主体章节按【认知递进】组织：是什么 → 为什么 → 怎么用 → 边界在哪
  类比与迁移锚点密度最高（S4 第 3 件套是重头——概念表已砍，类比是唯一的迁移载体）
  数字锚点表可较少，但概念必须准确

公司行业研究型
  主体章节按【时间线 + 因果链】组织：起源 → 转折 → 现状 → 格局
  必须交代生意模式（收入结构从哪来）与竞争格局（份额、对手、壁垒）
  S6 的对立立场是重头，跟踪指标表必须可执行

宏观策略型
  主体章节按【传导链条】组织：源头变量 → 传导路径 → 终端影响 → 配置含义
  必须画出传导链条（可并入 S3 主干流程）
  跟踪指标表以先行指标为主，注明发布频率

事件复盘型
  主体章节按【事件时间线 + 决策节点】组织
  每个关键决策点必须回答"当时能否预见"，区分事后诸葛与真实可见信号
```

## 第 4 章 · 金融属性类型的额外硬约束

适用于**公司行业研究型**与**宏观策略型**：

1. **信息时效必须显式**：附录 A1 元信息的「信息截止日」不得留空或写"未知"。若视频未明示日期，用视频内提及的最近事件反推，并注明"据视频内提及的 XX 事件推断"。
2. **利益相关方数据必须降级**：公司 CEO 对自家产品前景的判断、厂商自述的性能对比、卖方研究的目标价，一律不得标【实】。
3. **禁止投资建议**：不得出现"建议买入/卖出/加仓/减仓"、目标价、仓位建议。文末必须有"非投资建议"字样。
4. **立场必须对称**：S6 中对立两个立场的证据强度应大致相当。若视频本身一边倒，弱侧必须注明"视频未充分展开，以下为基于视频内事实的反向推演"。

## 第 5 章 · 判定示例

```
案例：《SK海力士崛起史：一个荒诞又狗血的财阀故事，如何卡住全球AI的脖子》
  步骤 1  围绕 SK海力士这家具体公司的历史、技术、竞争、供需展开？→ 是
  判定    公司行业研究型
  触发    S6 跟踪指标表 ✔
  元信息   … ｜ 内容类型：公司行业研究型 ｜ 蓝图版本：v5.0
          （类型名不含空格与斜杠；不再需要写"因此附加了…"清单）

案例：《大摩闭门会：AI军备竞赛的裂痕、存储周期的拐点与中国资产的窗口期》
  步骤 1  围绕具体公司展开？→ 否（多家机构分析师谈大类资产）
  步骤 2  围绕宏观经济、大类资产配置、市场策略展开？→ 是
  判定    宏观策略型
  触发    S6 跟踪指标表 ✔

案例：《Transformer 架构到底在算什么》
  步骤 1-3 均否
  判定    知识科普型
  触发    无（跟踪指标表不产出）
```
