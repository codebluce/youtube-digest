# 知识文章蓝图（Article Blueprint）

这是本 skill 的核心：字幕只是原料，**文章架构才是产品**。写作时必须严格遵守本文件的模块顺序和约束。

## 设计哲学（每个模块背后的学习科学）

| 模块 | 原理 | 效果 |
|---|---|---|
| 30秒速览 | 结论前置（advance organizer） | 读者先拿到答案，再看论证 |
| 知识地图 | 结构先行 | 读者始终知道"我在哪、还剩什么" |
| 章节+Takeaway | 分块（chunking）+ 检索练习 | 每章一个闭环，合上文章也能复述 |
| 章前引言（设问导入） | 章节级 advance organizer + 提问激活先备认知 | 读者带着问题和自己心里的猜测读正文，吸收率更高 |
| 数字锚点/类比 | 多重编码 | 同一事实以数字、故事、类比多种形式存储 |
| 系统性回顾 | 间隔重复 | 文末再过一遍全部要点，对抗遗忘曲线 |
| 转述弹药库 | 费曼技巧 | 能讲给别人 = 真正学会；谈资即传播 |

**目标读者画像**：没看过视频、愿意花 15–25 分钟深读的人。读完应达到三个标准：①能画出全片逻辑结构 ②能记住关键数字与结论 ③能向朋友转述 3 分钟以上。

## 文章模块（严格按此顺序）

### 模块 0 · 标题与元信息

- **主标题必须观点化**：用判断/冲突/悬念，不照抄视频原标题。
  - 差：《SK海力士的故事》 好：《SK海力士：卡住全世界AI脖子的公司》
- 元信息一行：来源频道 | 时长 | 整理日期。
- 一段 2–3 句的"本文导读"：这篇文章讲了什么、为什么值得读。

### 模块 1 · 30 秒速览（TL;DR）

3–5 条核心结论，每条一行、可独立成立。**只给结论，不给论证**（论证在正文）。读者 30 秒扫完就知道全片骨架。

### 模块 2 · 知识地图

表格：章节号 | 章节标题 | 一句话内容 | 本章回答的问题。
"回答的问题"一列最关键——它把章节从"名词"变成"任务"，读者带着问题读。

### 模块 3 · 背景钩子（可选，1 段）

如果视频开头本身就有强钩子（大新闻/冲突/悬念），保留并强化；如果没有，用一个"为什么这件事与你有关"的问题开场。超过 200 字就砍。

### 模块 4 · 主体章节（3–10 章）

每章固定五件套，顺序可微调但缺一不可：

1. **观点式章标题**：`## 三、海力士的诞生：一部存储行业洗牌史`，而非`## 三、海力士历史`。
2. **章前引言（设问导入）**：章标题之后、正文之前的一段预热，由 2–4 组"设问 + 简答"构成。
   - 设问从读者视角提出（"为什么…？""凭什么…？""还要多久？"），不得是章标题的同义重复；
   - 每组设问**立即附一句浓缩答案**（判断句）——先给答案再展开，是预热而不是留悬念；
   - 问题之间要有递进（是什么 → 为什么 → 意味着什么）；答案与本章 Takeaway 呼应但不重复措辞；
   - 统一用引用块呈现，与正文视觉区隔；总长 80–200 字。
   - 示例：
     > **内存比算力慢几十倍，AI 为什么没有被卡死？**——因为 HBM 把内存芯片叠成了 16 层楼。
     >
     > **三星产能更大，英伟达为什么偏偏选了 SK 海力士？**——赢在封装工艺的散热。
3. **重构叙事**（正文主体）：
   - 按时间线 / 因果链 / 对比结构**重写**，不是字幕搬运。去掉口癖、跳转语（"这段可以跳过""交给某某"），但保留视角切换的逻辑。
   - 优先用段落讲故事；事实密集处（收购史、时间表、份额对比）用**表格**。
   - 复杂概念配一个**类比**（如"TSV就是仓库大楼里的高速电梯"），类比优先沿用视频原句。
4. **关键数字锚点**：本章涉及的数字集中列表或小表格。所有数字必须来自字幕；字幕内部数字冲突时两个都保留并标注语境（如"IPO融资265亿 / 扩产计划筹资290亿"）。
5. **📌 Takeaway**：3–5 条，每条是**可独立成立的判断句**。
   - 差：`本节讲了HBM的三种技术。`
   - 好：`散热是HBM3之后竞争的分水岭——层数翻倍使三星TC-NCF路线的良率、工时、散热三重劣势同时爆发。`

### 模块 5 · 概念卡片盒

术语表：概念 | 一句话解释 | 为什么重要。收 5–15 个全片关键术语（如 HBM、TSV、MR-MUF、ADR、韩国折价）。读者读正文卡壳时回来查。

### 模块 6 · 系统性回顾

两部分：
1. **金字塔总结**：1 句话 → 3 大支柱 → 8–12 个要点（要点可引用各章 Takeaway，允许重复——重复即设计）。
2. **一张图**：全片时间线或结构关系，用表格或 ASCII 呈现。优先时间线。

### 模块 7 · 转述弹药库（可传播模块）

这是本 skill 区别于普通摘要的关键。全部子模块必须有：

1. **一句话版**：适合朋友圈/群聊开场。
2. **30 秒版**：3–4 句连贯的话，微信聊天直接念。
3. **3 分钟饭局版**：一段完整讲述，结构 = 钩子 → 冲突 → 反转 → 金句收尾。要能让人"讲出来"，不是"读出来"。
4. **金句 TOP 5**：优先用视频原话（核对字幕），可少量改写使其可独立引用。
5. **反常识冷知识 TOP 3**："你知道吗"体，每条附一个数字或细节。
6. **常见追问 Q&A**：3–5 个别人听完可能反问的问题 + 一两句答案（如"HBM和DDR有什么区别？"）。

### 模块 8 · 延伸思考（收尾）

未回答的问题、争议点（如视频中的两套对立叙事）、值得持续跟踪的指标/时间节点（如"2028 年产能释放"）。3–6 条即可。

## 写作铁律

1. **数字零编造**：文章里每个数字都能溯源到字幕。拿不准就删。
2. **冲突保留**：字幕内部矛盾如实并列 + 标注语境，不擅自二选一。
3. **重构非搬运**：任何一章如果读起来像逐段字幕，重写。
4. **Takeaway 用判断句**："X 意味着 Y"，不是"本节介绍了 X"。
5. **语言**：跟随视频主导语言，默认中文；术语首次出现给英文原名。
6. **篇幅**：以信息完整为准，通常 4000–12000 字；禁止为凑字数注水。
