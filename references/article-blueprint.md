# 知识文章蓝图（Article Blueprint）v2.0 — 范式锁定版

字幕只是原料，**文章架构才是产品**。

> ⚠️ **本文件是契约，不是建议。**
> 不同 agent 执行本 skill 必须产出结构一致的文章。为此，本蓝图对模块集合、模块顺序、标题锚点词、每模块最小满足量（DoD）做了硬性锁定。
> **产出后必须通过 `scripts/validate_output.py` 校验且 exit 0，才算完成。** 校验不过 = 未完成，不得交付、不得发送飞书。

---

## 第 0 章 · 强制规则（漂移控制）

违反任意一条即为不合格产出：

1. **模块集合锁定**：只能产出第 1 章模块表中列出的模块。**禁止新增自创模块，禁止删除必选模块，禁止调整模块顺序。**
2. **标题锚点词锁定**：每个模块的标题必须包含表中指定的「锚点词」，一字不差。章节序号（一、二、三…）可随主体章节数量浮动，锚点词不可改写、不可翻译、不可换同义词。
   - ✅ `## 十三、闭卷自测`　`## 闭卷自测`
   - ❌ `## 十三、自我检测`　`## 十三、Quiz`　`## 十三、闭卷测验`
3. **可信度符号白名单**：只允许 `【实】` `【推】` `【测】` 三个符号，半角方括号无效，禁止用 emoji、颜色、星号或英文缩写替代。
4. **数量下限硬性**：DoD 中的数字是**下限**，不是建议区间。写不满就说明挖掘不足，回去补，不得降标交付。
5. **条件模块由分型决定，不由 agent 心情决定**：先按 `references/content-types.md` 判定内容类型，判定结果决定哪些条件模块必选。判定过程必须写进文章头部的「内容类型」行。
6. **双产物**：每篇文章必须同时产出主文与卡片包两个文件，规格见 `references/cards-spec.md`。只交主文 = 未完成。
7. **数字零编造**：文章内每个数字都必须能溯源到字幕原文。拿不准就删，不许估算、不许换算后当原始数据、不许补全字幕没说的年份。

## 第 2 章 · 模块规格

### §2.00 标题与元信息 · M00

- **主标题必须观点化**：用判断、冲突或悬念，不照抄视频原标题。
  - ❌ `SK海力士的故事`
  - ✅ `SK海力士：一家两次被扫地出门的公司，如何卡住全世界AI的脖子`
- **元信息一行，5 项缺一不可**：来源频道 ｜ 时长 ｜ 整理日期 ｜ 信息截止日 ｜（频道主讲人，如视频有多位主讲）
- **导读 2–3 句**：这篇讲了什么、为什么值得读。禁止复述标题。

### §2.01 内容类型 · M01

一行，格式固定：

```
**内容类型**：`<类型名>` — 因此附加了<条件模块列表>
```

类型名与触发规则见 `references/content-types.md`。**禁止自创类型名。** 类型名按 content-types.md 的规范写法，不含空格与斜杠（✅ `公司行业研究型`，❌ `公司 / 行业研究型`）。「因此附加了」清单**只列条件模块**（M03/M11/M13/M16 中被触发的子集），不得混入立场脚手架等必选模块——校验脚本会解析该清单并与分型期望比对。

### §2.02 可信度总账 · M02

这是贯穿全文的标注体系，不是独立章节内容。

```
【实】  视频引用了公开数据、可查事实、已发生的事件
【推】  UP 主基于事实做出的逻辑推演（合理，但不是事实）
【测】  对未来的判断/预测，当下无法验证
```

**应用位置（三处，缺一不可）**：
1. M05 速览的每一条前置标记
2. M07 每章每条 Takeaway 前置标记
3. M07 数字锚点表必须有「来源强度」列

**总账行格式**：`全文 N 条核心论断 — 【实】a / 【推】b / 【测】c`，且 a+b+c = N。

**降级原则**：拿不准一律降级（实→推→测）。UP 主使用"我认为""应该""大概率""可能"等措辞的，一律不得标【实】。厂商自述数据（如"按 XX 公司的说法"）一律不得标【实】。

### §2.03 失效条件 · M03 `[条件模块]`

≥3 条，每条必须是**可观测事件**，不是主观感受。

- ❌ `如果行业景气度下降`
- ✅ `三星 HBM4 通过英伟达量产认证并进入放量`

### §2.04 阅读路径导航 · M04

≥3 档，用等宽代码块。必须指明每档看哪几个模块，不能只写时长。

### §2.05 30 秒速览 · M05

3–5 条，每条一行、可独立成立、**前置可信度标记**。只给结论，不给论证。

### §2.06 知识地图 · M06

**这是全文的思维导图，不是目录。** 一篇 8000–16000 字的文章，读者极易迷失在信息量里；知识地图的职责是让人在读之前就知道全文怎么走，读完之后能照着它复述。

**必须用等宽代码块承载**（飞书兼容、缩进可表达层级），**禁止用 Markdown 表格**。

分三段，缺一不可：

**① 一句话主线**（1 句判断句）
全文在讲什么。不是主题名词，是结论。

**② 主干流程**（5–7 个节点）
章与章之间**怎么推进**——因果链或时间线，用箭头连接。这是复述时的顺序骨架。

> 为什么必须有这一段：`问→答→据→结` 是**章内**结构，但复述最卡的地方从来不是单章讲不清，而是不知道怎么从第三章接到第四章。主干流程解决的正是这个。

**③ 分章四要素**
每章固定四行，用竖线对齐：

```
  问│ 本章要回答的问题（读者视角，与章前设问呼应但更短）
  答│ 本章的核心观点（一句判断句）
  据│ 关键论据与数字，用 ｜ 分隔，不超过 3 项
  结│ 本章小结（可压缩自 Takeaway，但必须更短）
```

- 用 `★` 标记主干章节（"只有 15 分钟就读这几章"）；
- **支线章节可压缩为两行**（只保留 `问│` 和 `结│`），控制总量；
- 四要素总量参考：8 章约 800–1000 字，占全文 <10%。

#### 铁律：所有节点必须是能说出口的判断句

导图的价值在于可直接复述，名词短语做不到这一点。

- ❌ `1.0 商业模式` / `技术原理` / `竞争格局`
- ✅ `最值钱的资产不是楼，是名字` / `散热是 12 层以上才暴露的分水岭`

#### 与其他模块的分工（防冗余）

| 模块 | 形态 | 职责 | 读者何时用 |
|---|---|---|---|
| **M06 知识地图** | 压缩版，强调**推进顺序**（流） | 导航 + 复述骨架 | 读之前 |
| M07 主体章节 | 展开版，完整论证 | 说服 | 读的过程 |
| M09 系统性回顾 | 归纳版，1 句→3 支柱（层） | 收拢 | 读之后 |

M06 是**流**，M09 是**层**，方向不同，不算重复。

**M06 与 M14 的关系**：主干流程 + 分章四要素照着念，就是一篇完整的 3 分钟版讲稿——**导图与 3 分钟稿是同一副骨架的图形态与口语态**，应互相印证。若两者讲的顺序不一致，说明有一个写错了。

### §2.07 主体章节 · M07

3–10 章。每章**五件套齐全，缺一不可**：

1. **观点式章标题**
   - ❌ `## 三、海力士历史`
   - ✅ `## 三、海力士翻身：一场封装工艺定生死的战争`

2. **章前引言（设问导入）**：2–4 组「设问 + 一句浓缩答案」，统一用引用块（`>`），总长 80–200 字。
   - 设问从读者视角提出，不得是章标题的同义重复；
   - 每组设问**立即附判断句答案**——先给答案再展开，是预热不是留悬念；
   - 问题之间要递进（是什么 → 为什么 → 意味着什么）。

3. **重构叙事**：按时间线 / 因果链 / 对比结构**重写**。去掉口癖与跳转语（"这段可以跳过""交给某某"），保留视角切换的逻辑。事实密集处（收购史、时间表、份额对比）**必须用表格**，不得用散文罗列。复杂概念配一个类比，类比优先沿用视频原句。

4. **关键数字锚点表**：三列 —— 数字 ｜ 含义 ｜ **来源强度**。
   来源强度取值示例：`公开史实` / `公司财报` / `视频引用第三方` / `UP主口述无源` / `厂商自述口径` / `庭审单方爆料`。
   字幕内部数字冲突时**两个都保留并标注语境**，不得二选一。

5. **📌 Takeaway**：3–5 条，每条是**前置可信度标记的独立判断句**。
   - ❌ `本节讲了HBM的三种技术。`
   - ✅ `【推】散热是HBM3之后竞争的分水岭——层数翻倍使三星TC-NCF路线的良率、工时、散热三重劣势同时爆发。`

### §2.08 知识网络 · M08

概念卡片盒的升级形态。表格五列：概念 ｜ 一句话解释 ｜ 为什么重要 ｜ **关系** ｜ **迁移锚点**。

- 收 5–15 个全片关键术语；
- **关系**列写该概念与其他概念的连接（上下游 / 对立 / 包含 / 引出）；
- **迁移锚点**列把概念挂到读者已有知识上（"这跟你熟悉的 X 是同一个逻辑"）；
- 表格下方**必须附 ASCII 关系图**，展示概念间的结构，不得省略。

### §2.09 系统性回顾 · M09

两部分，缺一不可：
1. **金字塔总结**：1 句话 → 3 大支柱 → 要点清单（要点可引用各章 Takeaway，重复即设计）
2. **一张图**：全片时间线或结构关系，ASCII 或表格，优先时间线

### §2.10 闭卷自测 · M10

**全文唯一真正的检索练习模块**，不可省略，不可用 Takeaway 替代。

- **5–8 题**，答案用 `<details><summary>展开答案</summary>…</details>` 折叠；
- **只出跨章综合题**：题目必须需要串联 ≥2 个章节才能回答，与章内 Takeaway 零重叠；
- **必须是解释型，不能是填空型**：
  - ❌ `HBM 堆了几层？`（查表即可，考的是记忆）
  - ✅ `三星产能更大、制程不落后，为什么在 HBM 上掉队？说出机制，不要只说"技术不行"。`
- **≥1 题必须考可信度分层**，如：`本文哪些结论属于【推】而非【实】？为什么这个区分重要？`
- 每题答案末尾附**回看指路**：`答不上 → 回看第三、四章`。

### §2.11 多空对照 · M11 `[条件模块]`

≥2 栏（看多 / 看空，可加第三栏如周期派）。每栏必须含四行：**核心论点 ｜ 最强证据 ｜ 最强反驳 ｜ 证伪信号**。建议加「验证窗口」行。

不得只列观点不列证伪信号——**没有证伪信号的立场不是判断，是表态**。

### §2.12 立场脚手架 · M12

≥2 个可选立场。每个立场必须含三部分：**论据（≥2 条）｜ 最强反驳（1 条）｜ 我错了的信号**。

目的是让读者挑一个变成自己的观点，而不是复述别人的观点。

### §2.13 跟踪清单 · M13 `[条件模块]`

≥5 个指标，五列：指标 ｜ 当前值 ｜ 关注阈值 ｜ 在哪看 ｜ 突破后意味着什么。

「在哪看」必须是具体信源（财报电话会 / 公司公告 / 行业价格数据），不得写"关注新闻"。

### §2.14 转述弹药库 · M14

**5 个子模块全部必选**，不存在"可选补充"：

**§2.14.1 三档主稿**
1. **30 秒版**：3–4 句连贯口语，微信可直接念。结构 = 钩子 → 关键判断 → 为什么重要。避免术语堆叠。
2. **3 分钟版**：结构 = 钩子 → 背景 → 冲突 → 反转/结论 → 金句收尾。要能"讲出来"，不是"读出来"。
3. **10 分钟版**：结构化讲稿，必须含核心论点、因果链、关键数字、反方视角、可跟踪指标。当 M11/M13 存在时，反方视角与可跟踪指标**应引用**这两个模块而非重复展开。

**§2.14.2 场景变体（3 个）**
对上级/会议 ｜ 对朋友/饭局 ｜ 对同行/行业交流。每个 2–3 句，**只改钩子和落点，不改事实**。
理由：谈资失败很少因为长度不对，而是场景不对。

**§2.14.3 追问攻防包**
- **3 个最可能的反驳 + 应答**。反驳写成真人口语（"那三星体量那么大，追上不是早晚的事？"），不是学术质疑。
- 应答给**可验证的判断依据**，不是嘴硬。
- **必须显式列出「🚧 该承认不知道的边界」**：哪些视频没讲、哪些数据厂商不公布。硬撑比承认不知道更掉价。

**§2.14.4 讲错风险清单（3–5 条）**
三类：❌ 易混数字 ｜ ❌ 易过度表述（"主导份额"≠"垄断"）｜ ⏳ 时效风险（写明"超过 X 个月别再引用"）。

**§2.14.5 金句 TOP 3–5**
优先用视频原话并核对字幕，可少量改写使其可独立引用。

### §2.15 延伸思考 · M15

3–6 条：未回答的问题、争议点（如视频中的两套对立叙事）、值得跟踪的时间节点。

### §2.16 UP主立场与利益相关 · M16 `[条件模块]`

四部分：
- **立场倾向**：叙事框架是什么，是否单向；
- **利益披露**：持仓声明 / 赞助标识 / 引流与预告；
- **信源质量**：**必须分部分评级**（技术 / 财务 / 政商 / 竞争各自可信度），不得一刀切；
- **引用建议**：哪部分可较高信任，哪部分必须降级为【推】。

## 第 3 章 · 写作铁律

1. **数字零编造**：每个数字可溯源到字幕。拿不准就删。
2. **冲突保留**：字幕内部矛盾如实并列 + 标注语境，不擅自二选一。
3. **重构非搬运**：任何一章如果读起来像逐段字幕，重写。
4. **Takeaway 用判断句**："X 意味着 Y"，不是"本节介绍了 X"。
5. **可信度不可省**：M05 与所有 Takeaway 必须带标记；拿不准一律降级。**把 UP 主的推演写成事实，是本蓝图最严重的错误。**
6. **自测题不许注水**：宁可只出 5 题，不要凑 8 题。任何一题若查一下原文就能答，说明出题失败。
7. **语言**：默认中文输出，即使视频主导语言是英文。术语首次出现可括注英文原名，后文以中文为主。
8. **篇幅**：主文 8000–16000 中文字。新增的标记、自测、攻防包主要以**标注和表格**承载，不得靠散文膨胀。事实密集处用表格是硬要求，不是风格偏好。

## 第 4 章 · 禁止清单

```
❌ 新增蓝图之外的自创模块
❌ 删除必选模块，或把必选模块降级为"可选补充"
```

## 附 · 设计哲学（每个模块背后的学习科学）

| 模块 | 原理 | 效果 |
|---|---|---|
| 30秒速览 | 结论前置（advance organizer） | 读者先拿到答案，再看论证 |
| 知识地图 | 结构先行 | 读者始终知道"我在哪、还剩什么" |
| 章节+Takeaway | 分块（chunking） | 每章一个闭环，可分段吸收 |
| 章前引言 | 章节级 advance organizer + 提问激活先备认知 | 带着问题读，吸收率更高 |
| 数字锚点/类比 | 多重编码 | 同一事实以数字、故事、类比多种形式存储 |
| 可信度分层 | 信源意识（epistemic tagging） | 知道哪句能说死、哪句只是推演 |
| 知识网络 | 图式建构（schema） | 概念之间有连接才存得住 |
| 系统性回顾 | 间隔重复 | 文末再过一遍，对抗遗忘曲线 |
| 闭卷自测 | 检索练习（retrieval practice） | 主动回忆才生成长期记忆 |
| 立场脚手架 | 生成效应（generation effect） | 自己选的立场比读来的观点记得牢 |
| 转述弹药库 | 费曼技巧 | 能讲给别人 = 真正学会 |
| 追问攻防 | 对抗性预演 | 谈资翻车不在讲不长，而在被追问一句就哑 |
| 卡片包 | 桌面参考（desk reference） | 长文没人看第二遍，卡片才会被反复翻 |

> ⚠️ **Takeaway 不是检索练习**。它是作者写好的判断句，读者只是"再读一遍并点头"（recognition），不产生长期记忆。真正的检索练习由 M10 闭卷自测承担——两者职责不同，不可互相替代。

**目标读者画像**：没看过视频、愿意花 15–25 分钟深读的人。读完应达到四个标准：①能画出全片逻辑结构 ②能记住关键数字与结论 ③能向朋友转述 3 分钟以上 ④**被追问时知道哪些能说死、哪些该承认不确定**。
