## v4.0 的由来（一次性说明，下一版删除本节）

v4.0 合并了两条同源的诊断。

**诊断一（来自 deck-spec v1.0）**：整条 pipeline 终止于 `validate exit 0`，但遗忘曲线在那一刻才开始。蓝图把 M09 系统性回顾称作"间隔重复"是概念错误——间隔重复的单位是天和周，同一次阅读里重复三遍叫 **massed practice**，不是 spaced practice。

**诊断二（本次实测）**：把 v2.1 的一篇成品逐模块量了字数——

```
主体章节（真正的内容）           40%
其余全部脚手架                   60%
其中同一结论的不同压缩比复述：
  30秒速览 → 知识地图分章四要素 → 各章Takeaway
  → 系统性回顾金字塔 → 三分钟稿             ≈ 全文 17%
```

**两条诊断指向同一件事**：文章内部堆再多重读型模块也不产生长期记忆，产生记忆的是跨天检索。deck-spec 自己在结尾写明"要到 20% 生成型占比需要的是**主体章节瘦身**，那是下一轮的事"——v4.0 就是那一轮。

## 第 0 章 · 强制规则（漂移控制）

违反任意一条即为不合格产出：

1. **模块集合锁定**：只能产出第 1 章表中的模块。禁止新增自创模块（含"全文总结""要点回顾""金句集锦""延伸阅读"这类收尾段），禁止删除，禁止调整顺序。
2. **标题锚点词锁定**：每个模块标题必须原样包含表中「锚点词」，一字不差。章节序号可随主体章节数量浮动，锚点词不可改写、翻译、换同义词。
   - ✅ `## 五、闭卷自测`　`## 闭卷自测`
   - ❌ `## 五、自我检测`　`## 五、Quiz`
3. **可信度符号白名单**：只允许 `【实】` `【推】` `【测】`。禁止半角方括号、emoji、星号、英文缩写。符号由**来源强度经 `scripts/credibility.py` 的映射表**决定，不由感觉决定。
4. **数量下限硬性**：DoD 中的数字是下限不是区间。写不满说明挖掘不足，回去补，不得降标交付。
5. **条件内容由分型决定**：先按 `references/content-types.md` 机械判定内容类型，判定结果写进附录 A1 的元信息行。v5.0 起唯一的条件内容是 S6 的跟踪指标表。
6. **数字零编造**：每个数字必须可溯源到字幕原文。拿不准就删，不许估算、不许换算后当原始数据、不许补全字幕没说的年份。
7. **后置 ≠ 降级成纯文本**：附录里的 A1 仍然是一个**有标题的模块**（`### 来源频道`），不是一段散文。实测中最常见的漂移是：搬家搬了一半，标题丢了、内容还在，于是子串匹配照样通过，而模块实际上已经不存在了。

## 第 2 章 · 模块规格

### §S0 导读

**紧跟主标题，不带标题行**，2–3 句、40–260 字。它是主标题的延长线，不是一个模块。

内容只回答三件事：**这篇讲什么 ｜ 为什么值得读 ｜ 读完你能做什么**。财经类型在此写明"非投资建议"。

> **为什么前置。** 附录是读完之后才会翻的地方。把"这篇讲什么、值不值得读"压在文末，等于在读者最需要它的那一刻不给他——他要在第一屏决定读不读，而不是读完再回头确认自己没读错东西。

#### 铁律：导读不给结论

- ❌ 禁止出现 `【实】【推】【测】` 任何标记——带标记的是论断，论断属于 S2 速览；
- ❌ 禁止复述主标题；
- ❌ 禁止提前说出全片的核心判断——那会让 S1 读前预判当场失效：读者在猜之前就拿到了答案，前测效应归零。

说"这篇讲他怎么把定价锚换掉了"是导读；说"他把定价锚从品牌好感换成了权力距离"是结论，不能写在这里。

### §S1 读前预判

正文第一个模块。**3 题，只问不答。**

- 题目问的是本文将要回答的核心问题，读者此刻**不可能知道答案**；
- 每题后留一行 `我的猜测：` 空着，让读者写；
- **禁止在本模块给答案，也禁止暗示答案**——给了答案就退化成第二份速览。

> 为什么放在速览之前：先猜后读（pretesting）会激活先备认知并制造预期违背，
> 哪怕猜错——尤其是猜错——后续内容的记忆强度都显著高于直接读。这是全文
> 成本最低的生成型模块，约 100 字。

### §S2 30 秒速览

3–5 条，每条一行、可独立成立、**前置可信度标记**。只给结论，不给论证。

### §S3 全片脉络

**必须用等宽代码块承载**（飞书兼容、缩进可表达层级），禁止用 Markdown 表格。两段：

**① 一句话主线** —— 全片在讲什么。不是主题名词，是结论判断句。

**② 主干流程** —— 5–7 个节点，用箭头连接，展示章与章之间**怎么推进**（因果链或时间线）。用 `★` 标记主干章节（"只有 15 分钟就读这几章"）。

#### 铁律：所有节点必须是能说出口的判断句

脉络图的价值在于可直接复述，名词短语做不到这一点。

- ❌ `1.0 商业模式` / `技术原理` / `竞争格局`
- ✅ `最值钱的资产不是楼，是名字` / `散热是 12 层以上才暴露的分水岭`

主干流程照着念，就是 S7 的 3 分钟稿骨架——**两者是同一副骨架的图形态与口语态**，顺序必须一致。若不一致，说明有一个写错了。

### §S4 主体章节

3–8 章。每章**五件套齐全，缺一不可**：

1. **观点式章标题**
   - ❌ `## 三、海力士历史`
   - ✅ `## 三、海力士翻身：一场封装工艺定生死的战争`

2. **章前设问（延迟一答）**：1–2 组设问，统一用引用块（`>`），总长 60–120 字。设问从读者视角提出，不得是章标题的同义重复。

   **每章至少 1 组必须"延迟一答"**：引言里只提问、不给答案，答案留在正文对应位置，并在那一句后面标注 `↑ 回答了章前第N问`。

   > 为什么不全部立即给答案：立即给答案是 advance organizer，服务理解；延迟一答制造的是一个**提取间隙**——读者带着未闭合的问题往下读，读到答案那一刻发生的是提取而非接收。两者都要，所以每章保留至少一组延迟。第二组（若有）可以立即给答案作为保底。

3. **重构叙事**：按时间线 / 因果链 / 对比结构**重写**。去掉口癖与跳转语，保留视角切换的逻辑。事实密集处（收购史、时间表、份额对比）**必须用表格**，不得用散文罗列。
   **复杂概念必须配一个类比，并把类比挂到读者已有知识上**（"这跟你熟悉的 X 是同一个逻辑"）——这承接了原「知识网络·迁移锚点」的职责，是概念能否长期存住的关键，不是修辞装饰。类比优先沿用视频原句。

4. **关键数字锚点表**：三列 —— 数字 ｜ 含义 ｜ **来源强度**。
   来源强度取值示例：`公开史实` / `公司财报` / `视频引用第三方` / `UP主口述无源` / `厂商自述口径` / `庭审单方爆料`。
   **来源强度决定这个数字在别处出现时能挂哪个符号**，映射见 `scripts/credibility.py`，validator 会逐个数字比对。字幕内部数字冲突时**两个都保留并标注语境**，不得二选一。

5. **📌 Takeaway**：3–5 条，每条是**前置可信度标记的独立判断句**。
   - ❌ `本节讲了HBM的三种技术。`
   - ✅ `【推】散热是HBM3之后竞争的分水岭——层数翻倍使三星TC-NCF路线的良率、工时、散热三重劣势同时爆发。`

### §S5 闭卷自测

**全文唯一真正的检索练习模块**，不可省略，不可用 Takeaway 替代。v4.0 砍掉了全部重读型模块，本模块的地位相应上升，同时它是卡组的主要来源。

- **5–8 题**，答案用 `<details><summary>展开答案</summary>…</details>` 折叠；
- **只出跨章综合题**：题目必须串联 ≥2 个章节才能回答，与章内 Takeaway 零重叠；
- **必须是解释型，不能是填空型**：
  - ❌ `HBM 堆了几层？`（查表即可，考的是记忆）
  - ✅ `三星产能更大、制程不落后，为什么在 HBM 上掉队？说出机制，不要只说"技术不行"。`
- **≥1 题必须考可信度分层**，如：`本文哪些结论属于【推】而非【实】？为什么这个区分重要？`
- 每题答案末尾附**回看指路**：`答不上 → 回看第三、四章`。

### §S6 立场与证伪

合并了原失效条件、多空对照、立场脚手架、跟踪清单——四者在认知上是同一个操作：**说出可观测的反证条件**。

**① 立场（≥2 个，财经类型建议含对立的两个）**

每个立场三部分：

```
论据          ≥2 条
最强反驳      1 条
我错了的信号   必须是可观测事件，不是主观感受
```

- ❌ `如果行业景气度下降`
- ✅ `三星 HBM4 通过英伟达量产认证并进入放量`

**没有「我错了的信号」的立场不是判断，是表态。**

若视频本身一边倒，弱侧立场必须注明"视频未充分展开，以下为基于视频内事实的反向推演"。

目的是让读者挑一个变成自己的观点，而不是复述别人的观点。

**② 跟踪指标表**〔条件：公司行业研究型 / 宏观策略型必选〕

≥5 个指标，五列：指标 ｜ 当前值 ｜ 关注阈值 ｜ 在哪看 ｜ 突破后意味着什么。

「在哪看」必须是具体信源（财报电话会 / 公司公告 / 行业价格数据），不得写"关注新闻"。

### §S7 转述与攻防

四部分，全部必选：

**① 30 秒稿**：3–4 句连贯口语，微信可直接念。结构 = 钩子 → 关键判断 → 为什么重要。避免术语堆叠。

**② 3 分钟稿**：结构 = 钩子 → 背景 → 冲突 → 反转/结论 → 金句收尾。要能"讲出来"，不是"读出来"。顺序必须与 S3 主干流程一致。

**③ 追问攻防**：3 组反驳 + 应答，每组以 `Q：` / `A：` 开头。反驳写成真人口语（"那三星体量那么大，追上不是早晚的事？"），不是学术质疑；应答给**可验证的判断依据**，不是嘴硬。

### §附录 · 元信息与校验口径

一个 `## 附录、元信息与校验口径`，其下只有一个 `### 来源频道`：

- **元信息一行，6 项缺一不可**：来源频道 ｜ 时长 ｜ 整理日期 ｜ 信息截止日 ｜ 文本来源（官方字幕 / 本地 ASR 转写）｜ 内容类型 ｜ 蓝图版本
  内容类型写在这一行里，不再单独成节；类型名见 `content-types.md`，禁止自创、不含空格与斜杠。
- **导读已于 v5.1 前置到主标题下方（见 §S0），不再放在附录里。**
- **三符号说明**：

```
【实】视频引用了公开数据、可查事实、已发生的事件
【推】UP 主基于事实做出的逻辑推演（合理，但不是事实）
【测】对未来的判断/预测，当下无法验证
```

  **降级原则**：拿不准一律降级（实→推→测）。符号不是自由裁量——由数字锚点表的「来源强度」经 `scripts/credibility.py` 映射得出。厂商自述、CEO 预测、庭审单方爆料、UP 主口述无源一律不得标【实】；任何指向未来的表述一律【测】，"公司财报里的 2027 年产能目标"也是【测】。

**主标题必须观点化**（写在文件第一行 `#`）：用判断、冲突或悬念，不照抄视频原标题。
- ❌ `SK海力士的故事`
- ✅ `SK海力士：一家两次被扫地出门的公司，如何卡住全世界AI的脖子`

## 第 3 章 · 写作铁律

1. **数字零编造**：每个数字可溯源到字幕。拿不准就删。
2. **冲突保留**：字幕内部矛盾如实并列 + 标注语境，不擅自二选一。
3. **重构非搬运**：任何一章如果读起来像逐段字幕，重写。
4. **Takeaway 用判断句**："X 意味着 Y"，不是"本节介绍了 X"。
5. **可信度不可省，也不可自由裁量**：S2 与所有 Takeaway 必须带标记；符号由来源强度映射决定。**把 UP 主的推演写成事实，是本蓝图最严重的错误。**
6. **自测题不许注水**：宁可只出 5 题，不要凑 8 题。任何一题若查一下原文就能答，说明出题失败。
7. **不许把砍掉的模块变相写回来**：不得新增"全文总结""要点回顾""金句集锦""延伸阅读"等收尾段——那正是 v4.0 要砍的重复暴露。
8. **语言**：默认中文输出，即使视频主导语言是英文。术语首次出现可括注英文原名，后文以中文为主。
9. **篇幅**：主文 6000–12000 中文字（v2.1 为 8000–16000，缩减来自脚手架而非内容）。事实密集处用表格是硬要求，不是风格偏好。
10. **单产物**：默认只交主文。记忆卡组 `<stem>-deck.tsv` 是**按需**产物（规格见 `references/deck-spec.md`），只有用户明确要求时才为那个视频生成——不要主动产出，也不要因为没有卡组就认为未完成。

## 附 · 保留下来的每个模块背后的学习科学

分两栏。**服务理解**的模块帮助读者当场读懂；**服务记忆**的模块产生跨天可提取的痕迹。v2.1 的问题是第一栏堆了七八个、第二栏只有一个。

| 模块 | 原理 | 服务 |
|---|---|---|
| S1 读前预判 | 预测试效应（pretesting） | **记忆** |
| S0 导读 | 定向（orienting response） | 理解 |
| S2 30秒速览 | 结论前置（advance organizer） | 理解 |
| S3 全片脉络 | 结构先行 | 理解 |
| S4 章前设问（延迟一答） | 提取间隙 + 章节级 advance organizer | 理解 / **记忆** |
| S4 分章 + Takeaway | 分块（chunking） | 理解 |
| S4 数字锚点 + 类比 | 多重编码 + 迁移 | 理解 / 记忆 |
| S4 可信度分层 | 信源意识（epistemic tagging） | 理解 |
| S5 闭卷自测 | **检索练习（retrieval practice）** | **记忆** |
| S6 立场与证伪 | 生成效应（generation effect） | **记忆** |
| S7 转述与攻防 | 费曼技巧 + 对抗性预演 | **记忆** |
| 卡组 + 复习队列 | **间隔重复（真·spaced practice）** | **记忆** |

> ⚠️ **Takeaway 不是检索练习。** 它是作者写好的判断句，读者只是"再读一遍并点头"（recognition），不产生长期记忆。真正的检索练习由 S5 与卡组承担。v2.1 靠堆叠重读型模块（知识地图四要素、系统性回顾、10 分钟稿）制造"学到了"的感觉——v4.0 删掉它们，把预算移到跨天检索上。
>
> **间隔重复的「间隔」单位是天和周，不是段落之间的 300 字。** 同一次阅读里重复三遍是 massed practice。这条曾被写成"M09 系统性回顾 = 间隔重复"，是概念错误，v4.0 一并更正。

**目标读者画像**：没看过视频、愿意花 15–25 分钟深读的人。读完应达到四个标准：①能画出全片逻辑结构 ②能记住关键数字与结论 ③能向朋友转述 3 分钟以上 ④**被追问时知道哪些能说死、哪些该承认不确定**。第 ② 项由卡组在 D+1/3/7/16/35 上兑现，不由主文兑现。
